# Tensura 26.3 Modpack — Compatibility Candidate

**Required NeoForge version: 26.3.0.45-beta**

Minecraft version: **26.3**.

This separate candidate additionally passes headless startup and 69 checks on **NeoForge 26.3.0.99**. The main branch remains the original pack pinned to 26.3.0.45-beta.

Use the complete mods folder from this branch. It replaces Architectury 22.0.3 with a compatibility build based on upstream 22.0.5. Keep only one Architectury JAR. The other 14 JARs are unchanged. Matching source and the compatibility patch are embedded in the updated dependency JAR.

Verification covers 7 actual tool/biome controls and 62 related integration rows on each tested loader. No client or GPU test was run; confirmation on the other player's PC is still needed. This does not claim support for every older, intermediate or future NeoForge 26.3 build.
