# Tensura 26.3 Modpack - 428

Minecraft **26.3**. Use **NeoForge 26.3.0.99** or **NeoForge 26.3.0.45-beta**.

Download **Code → Download ZIP**, extract it, then copy the complete `mods` folder into your Minecraft instance. Install the same set on the client and server. Replace previous versions of these mods; keep only one Architectury JAR (`architectury-neoforge-22.0.5.427.jar`).

Version 428 fixes Body Double recursion, creator/sibling ally relationships and compatible humanoid skin copying. It also makes explicit NPC skill revocations persist against automatic restoration; an explicit ability grant can restore a revoked skill.

Verification: 25 targeted checks passed on each listed NeoForge version, 2 cold-JVM persistence checks passed on 45-beta, and the related combined 45-beta regression passed 67 assertions. The 99 game client was also launched with this exact set of 15 JARs. Other NeoForge builds have not been individually verified; gameplay and rendering on every computer are not guaranteed by these checks.
